# 무이성형외과 홈페이지 개편 점검 보고서 및 일정표

`무이성형외과_홈페이지개편_점검보고서_및_일정표.pdf` — 점검 보고서(개선안)와 AI 검색 최적화 4주 일정표를 하나로 통합한 PDF 문서입니다.

## 구성 (3페이지)

- **Part 1. 홈페이지 개편 점검 보고서** (개선안)
  - 0. 총평 / 1. 좋아진 점 / 2. 보완 필요 / 3. 후퇴한 점 / 4. Before·After 비교표 / 5. 보완 우선순위 / 6. 맺음말
- **Part 2. AI 검색 최적화 4주 일정표** (실행 일정)
  - 1. 일정 요약 / 2. 주차별 일정 / 3. 수행 범위 구분 / 4. 일정 기준

진단(보고서) → 실행 계획(일정표) 순서로 배치했습니다.

## 원본 대비 수정 내용

검토 요청에 따라 개선안에서 아래 내용을 삭제하고, 통합 문서 전체의 일관성을 위해 일정표에서도 관련 항목을 정리했습니다.

**네이버 검색 관련 삭제**
- 총평 '보완 필요'의 `네이버 미연동` 문구
- 2장 전환 측정 행의 측정 태그 목록에서 `네이버` 제거
- 2장 `네이버 연동` 행 전체
- 4장 비교표 `네이버 연동` 행 전체
- 5장 우선순위의 2순위 `네이버 플레이스·예약·톡톡 연동` 항목 삭제 후 재번호 (1순위 유지, 기존 3·4·5순위 → 2·3·4순위)
- 일정표 '별도 확장 가능 항목'의 `네이버/` 문구 (일관성 정리)

**main 도메인 관련 삭제**
- 부제목의 `(main)` 표기
- 총평 '후퇴'의 `대표 제목에 'main' 잔재`, `수정본이 아직 첫 화면(루트)에 미적용` 문구
- 4장 비교표 머리글의 `수정본(main)` → `수정본`, `이전(/)` → `이전`
- 4장 비교표 `첫 화면(루트) 적용` 행 전체
- 맺음말 각주의 `(mooips.com/)`, `(mooips.com/page/main)` URL 표기

## 다시 빌드하려면

```bash
cd source
npm install playwright-core          # 최초 1회
node makepdf.js report.html ../무이성형외과_홈페이지개편_점검보고서_및_일정표.pdf
```

- 내용 수정은 `source/report.html` 에서 합니다.
- 한글 렌더링에는 나눔 글꼴(NanumSquare / NanumBarunGothic)이 필요합니다.
