# 오늘의 던파운세 — 아라드 데일리 오라클

던전앤파이터 유저 커뮤니티에 시딩하기 위한 비공식 팬 콘텐츠 사이트.
회원가입 없이 모험단명만 입력하면 오늘 하루의 던파 운세를 보여주는 정적 원페이지(`index.html`)로,
어떤 정적 호스팅(GitHub Pages, Cloudflare Pages 등)에도 파일 하나로 배포 가능하다.

## 콘텐츠 구성

| 섹션 | 내용 |
|---|---|
| 운세 등급 | 결과 자체에 아이템 등급(레어→유니크→레전더리→에픽→태초)을 부여. 태초는 3% 확률 |
| 조율자 명당 | 최후의 조율자 추천 채널(1~40) + 추천 시간대 + 플레이버 텍스트 |
| 강화소 기상도 | 장비 증폭운 / 무기 강화운 / 봉인된 자물쇠 별점(1~5) + 코멘트 |
| 오늘의 막공운 | 공대 성공률 %(17~99) |
| 미니 운세 | 행운의 직업, 행운의 물건, 오늘의 금기 |
| 오늘의 한 마디 | NPC 어록 패러디 |

## 바이럴 설계 의도

- **희귀 등급 = 스크린샷 유도**: 3% 확률의 '태초 운세'가 뜨면 카드에 프리즘 테두리 연출이 붙는다.
  낮은 확률의 당첨 화면은 커뮤니티 인증글의 단골 소재("태초운세 떴다")가 된다. 반대로 최하 등급(레어)도
  "오늘 운세 레어 뜸 ㅋㅋ" 식의 자학 밈으로 공유된다 — 양극단 모두 공유 동기가 있다.
- **하루 고정 결과(결정론적 시드)**: 모험단명 + KST 날짜로 시드를 만들어 같은 이름은 하루 종일 같은 결과.
  "진짜 운세" 느낌을 주고, 길드원끼리 서로 이름을 넣어 비교하는 놀이가 성립한다. 자정 리셋은 재방문 동기.
- **커뮤니티 최적화 복사 포맷**: '결과 복사하기'가 이모지 구분선이 들어간 게시판 친화 텍스트를 생성.
  인증글 작성 마찰을 0에 가깝게 줄인다. 링크 공유는 `?adv=모험단명` 파라미터로 결과가 재현된다.
- **무마찰 진입**: 회원가입·로그인·개인정보 수집 없음(입력값 미저장 고지). 커뮤니티 특성상
  수집 낌새가 보이면 역바이럴이 나므로 명시적으로 고지한다.
- **면책 고지**: 비공식 팬 콘텐츠임과 실제 게임 확률과 무관함을 푸터에 명시 — IP 리스크와
  "확률 낚시" 반감을 모두 차단한다.

## 기술 메모

- 의존성 없는 순수 HTML/CSS/JS 단일 파일. 다크 단일 테마(게임 세계관에 맞춘 선택).
- 시드: FNV-1a 해시 → mulberry32 PRNG. 등급이 별점 분포에 소폭 가중치를 줘 등급과 세부 운세가 따로 놀지 않는다.
- `prefers-reduced-motion` 대응, 모바일 우선 레이아웃(커뮤니티 링크 유입은 대부분 모바일).
