# 개발사 커뮤니케이션 (카카오톡)

## 1) 보낸 메시지 — 수정·보완 요청서 (최종본)

> 어투: 부드럽게 / 괄호 속 영어 제거 / 분석 기준 페이지 명시 / 버튼 항목은 모바일·데스크톱 공통 / 동의 링크 항목 없음(정상 확인).

```
안녕하세요. 무이성형외과 홈페이지를 점검하면서 확인한 내용을 정리해 보았습니다. 편하신 시간에 검토 부탁드리며 문의사항 있으실 경우 말씀 부탁드립니다.
※ 아래 내용은 https://www.mooips.com/page/main 페이지를 기준으로 살펴본 결과이며, 우선순위 순으로 정리했습니다.

[1] GA4 전환 측정 설치 (가장 먼저 권해드립니다)
현재는 방문자 수 정도만 집계되고 있어, 그 방문이 실제 상담·예약까지 이어졌는지는 확인하기 어려운 상황으로 보입니다(이전 홈페이지의 기존 분석 도구도 빠져 있는 듯합니다).
이 부분을 보완하면, 어떤 경로(검색·블로그·광고 등)로 들어온 분이 상담까지 이어지는지 숫자로 확인할 수 있습니다. 효과 있는 채널에 광고비를 집중하고 낭비를 줄이는 데 도움이 될 것으로 기대됩니다.

진행 방식 (역할 구분)
- 측정 계정·아이디: 병원 명의로 저희가 만들어 전달드리려고 합니다. 사이트 접근이 필요 없는 부분이라 저희 쪽에서 준비하며, 데이터는 병원이 직접 소유하게 됩니다.
- 개발사: 전달드린 측정 코드를 전체 페이지에 설치만 해주시면 됩니다.
- 구글 서치콘솔: 등록 시 사이트 인증이 필요해, 인증 절차만 협조해 주시면 감사하겠습니다.

[2] 화면 구성 보완
- 전문의·전담 마취과 전문의 등 의료진 신뢰 정보를 첫 화면에도 노출시키는 것을 추천드립니다.
- 버튼 크기·간격과 버튼 이름(라벨)도 함께 살펴봐 주시면 감사하겠습니다. 현재 버튼이 다소 작고 가까이 붙어 있으며 이름이 비어 있어, 잘못 눌릴 여지가 있고 점검에서도 보완이 권장되었습니다(모바일·데스크톱 공통).

[3] 검색·AI 노출 정비
- 주요 메뉴·링크를 검색엔진이 수집할 수 있는 형태로 정비해 주시는 것을 추천 드립니다(현재는 수집이 어려운 것으로 확인됩니다).
- 이미지 설명 문구(대체텍스트)도 함께 추가해 주시면 감사하겠습니다(점검에서 일부 누락이 확인됩니다).
- 대표 페이지 제목과 페이지별 설명 문구도 다듬어 주시면 좋겠습니다.

[4] 이미지·로딩 속도 개선
- 이미지 용량을 한 번 최적화하는 것을 추천 드립니다(전체 약 15MB로 다소 무겁고, 이미지에서만 3MB 이상 줄일 여지가 있는 것으로 확인됩니다).
- 이미지 크기 값 지정과 지연 로딩도 적용해 주시면, 느린 환경에서의 로딩 지연을 줄이는 데 도움이 될 것 같습니다.

함께 공유 부탁드릴 점 — 홈페이지 수정 가능 범위와 반영 절차 정도만 알려주시면 진행에 도움이 될 것 같습니다.
※ 구조화 데이터 등 검색 최적화 파일은 점검·설계가 마무리되는 대로 적용 안내와 함께 전달드리겠습니다.
```

## 2) 개발사 회신 요약
- [4]는 바로 진행 가능.
- [1]~[3]은 "수정/추가할 스크립트·항목을 정리해서 전달해 주면 작업하겠다".
- [3]의 '주요 메뉴·링크 크롤링' 항목이 이해가 안 됨 → 자세한 설명 요청.

## 3) 회신에 대한 우리 답장 (작성본)

```
안녕하세요! 검토해 주셔서 감사합니다.

[4] 이미지·로딩 속도부터 진행해 주신다니 감사합니다. 반영해 주시면 확인하겠습니다.

[1]~[3]은 저희 쪽에서 필요한 코드와 구체 항목을 정리해 전달드리겠습니다. 항목별로 이렇게 준비하려고 합니다.
- [1] GA4: 측정 코드(스크립트)를 저희가 발급해 전달드릴 테니, 받으시면 전체 페이지 공통 영역(head)에 넣어주시면 됩니다. 서치콘솔 인증 방법도 함께 안내드리겠습니다.
- [2] 화면 구성: 첫 화면에 노출할 의료진 정보와 위치, 버튼 이름(라벨)·권장 크기 등을 정리해 전달드리겠습니다.
- [3] 검색·AI: 페이지 제목·설명 문구와 이미지 대체텍스트를 정리해 전달드리겠습니다.

문의 주신 [3]의 '링크 수집(크롤링)' 항목을 조금 더 풀어서 설명드리면 —
쉽게 말해, 검색엔진·AI가 메뉴를 눌러 하위 페이지로 '따라 들어가지' 못하는 상태입니다.
- 원리: 검색엔진은 페이지 안의 링크(<a href="주소">)를 따라가며 사이트를 수집합니다.
- 현재: 주요 메뉴·링크가 실제 이동 주소(href) 없이 자바스크립트 클릭이나 '#' 형태로만 되어 있어, 크롤러가 하위 페이지로 이동하지 못하는 것으로 보입니다.
- 영향: 시술·의료진·이벤트 등 하위 페이지가 검색·AI 결과에 잘 노출되지 않을 수 있습니다.
- 해결: 주요 링크에 실제 페이지 주소를 담은 정상 링크(예: <a href="/실제-주소">코성형</a>)를 넣어주시면 됩니다. 기존 자바스크립트 동작은 그대로 두시고, href에 실제 주소만 함께 넣어주시면 됩니다.
- 대상 확인: 어떤 링크가 해당되는지는 PageSpeed Insights의 '링크를 크롤링할 수 없음' 항목에서 목록으로 보실 수 있습니다.

이 항목은 사이트 구조와 관련된 부분이라, 구체적인 대상 링크는 개발사에서 확인하시는 편이 수월하실 것 같아 설명으로 전달드립니다. 나머지 [1]~[3] 자료는 정리되는 대로 순차적으로 보내드리겠습니다.

감사합니다!
```

- [2] 첫 화면 의료진 문구·위치 / 버튼 라벨·권장 크기(24px 이상, 간격 확보)
- [3] SEO 확정본 → `handoff/seo-draft.md` (메뉴·전문과목 채운 뒤)
