## 3. 분석 핵심 결론 (데이터 근거, 확정)

1. **"첫날 ~550회 후 급사" 패턴**: 전 영상이 게시 당일 약 520~550회(쇼츠 알고리즘의 초기 테스트 노출)를 받은 뒤 다음날부터 한 자릿수로 급락. 원인은 시청 지속률 부족(평균 조회율 49.7%). 쇼츠가 추천 피드를 타려면 조회율 75~90%+, 루프 포함 100%+ 필요. **최대 병목 = 완주율.**
2. **CTR은 이미 강점** (상위 영상 8~9%). 썸네일/제목 후킹 능력은 검증됨.
3. **구독 전환 사실상 0** (0.06%). 채널 정체성·인물 브랜딩·참여 장치 부재가 원인.
4. **이상적 길이 35~45초**: 42초 영상이 조회율 72%로 1위, 84초는 20%로 꼴찌.
5. **제목은 문제 해결형이 승리**: "기영이 머리 탈출", "하관 콤플렉스 삭제"가 상위권. "2026 남자 헤어 추천ㅣ" 동일 접두어 반복 영상은 전부 하위권.
6. **여아 헤어 등 주제 이탈 콘텐츠는 채널 시그널을 흐림** — 신규 채널에서 금지.

## 4. 확정된 전략 결정사항 (재논의 불필요)

1. **톤앤매너: 나레이션 + 코믹(웃긴) 톤 확정.** 나레이션+코믹으로 만든 두 영상(기영이머리 드롭컷, "두쫀쿠")만 성과가 유의미하게 좋았음. 기영이머리는 조회수·조회율 모두 1위. 팀 내 합의 완료, 정식 채널의 기본 편집 방향.
2. **비포/애프터 쇼츠도 이 방향으로 편집 방향 수정.** 기존 세이빙(편집 완료 대기) 영상에는 나레이션만 추가해 업로드 후 반응 확인.
3. **수익화 구조: 롱폼 = 수익, 쇼츠 = 유입.** 쇼츠 광고 RPM이 매우 낮아 롱폼 시청 4,000시간 + 구독 1,000명(YPP) 경로가 본선. 유튜브 쇼핑은 YPP 가입 이후에만 가능하므로 "롱폼으로 YPP 달성 → 쇼핑 부착" 순서. 그 전에는 설명란 외부 제휴 링크 활용.
4. **롱폼 메인 포맷: 사연 해결형 8~12분** (고민 인터뷰 → 스타일 설계 설명 → 시술 하이라이트 → 리액션). "긴 쇼츠"를 만들지 말 것. 보조 포맷: 고민 키워드 강의형(검색 자산), 랭킹형, 제품 실험형.
5. **제작 파이프라인: 시술 1회 촬영 = 롱폼 1편 + 쇼츠 3편** (변신컷/팁컷/리액션컷). 촬영 시 인터뷰 3질문, 상담 장면, 리액션 2앵글, 동일 앵글 비포/애프터 확보.
6. **구독 장치: "댓글 사연 → 다음 화" 참여 루프 + 시리즈 넘버링** (기우쌤 성장 공식).
7. **9월 론칭 플랜**: 8월 12~15편 선제작 → 9월 1~2주 매일 업로드(시딩) → 3~4주 주 4~5편 + 첫 롱폼. 업로드 시간 평일 18~21시. KPI: 조회율 75%+, 구독 전환 0.5%+, 3개월 내 1,000구독.

## 5. 벤치마크 조사 요약

- **기우쌤 (~132만, 국내 1위 미용사 유튜버)**: "망한 머리 살리기" 사연 참여형. 본인 인터뷰: "예쁜 머리만 보여주면 공감이 안 된다." → 우리의 사연 참여 루프의 근거.
- **송샘 (~25만)**: "남자머리 해결사" 포지셔닝, 고민 키워드(탈모, 손질법) 롱폼 482개의 검색 자산형 채널.
- **킹스턴맨즈헤어**: 샵 예약 + 바버 아카데미로 채널 밖 수익화 (미용사 채널의 종착 모델).
- **헤어몬 (~31만)**: 셀럽 레버리지. → 우리는 "OO 배우 머리, 일반인 버전" 포맷으로 응용.
- **해외**: Slikhaar TV(210만, 셀럽 헤어 재현), BluMaan(150만, 월·금 고정 업로드 + 자체 제품).
- **시장 공백 2가지**: ① 쇼츠 네이티브 남자 헤어 절대 강자 부재, ② 여성(파트너) 타겟 "남친/남편 머리 바꿔주기" 관점 채널 부재 — 우리의 차별화 포인트.

- 세이빙(편집 완료 대기) 영상에는 나레이션만 추가해 업로드하고 반응을 볼 예정.
- 팀원 유라님이 제작한 쇼츠도 반응이 좋았다는 내부 피드백(재범님) 있음.

## 7. 용어/맥락 메모

- **두쫀쿠**: 팀 내부에서 부르는 영상 별칭. 나레이션+코믹 톤으로 제작된 두 번째 영상. 길이가 다소 길어 기영이머리보다는 성과가 낮지만 양호.
- **세이빙**: 편집 완료 후 업로드 대기 중인 영상들.
- **기영이 머리**: 만화 '검정고무신' 캐릭터의 촌스러운 머리를 비유한 표현. 성과 1위 영상의 콘셉트.
- 데이터의 연도가 2026년으로 표기된 것은 원본 데이터 그대로임.
