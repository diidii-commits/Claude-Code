## 점검 검증 결과 (보고서 주장 vs 실제)
PageSpeed Insights(모바일/데스크톱) + view-source 로 직접 확인.

| 항목 | 결과 |
|---|---|
| GA4·측정 태그 0 | ✅ 사실 (gtag·googletagmanager 모두 미검출) |
| 에이스카운터 제거 | ✅ 사실 (미검출) |
| 이미지 alt 누락 | ✅ 사실 (접근성·SEO, 모바일·데스크톱 공통) |
| 링크 크롤링 불가 | ✅ 사실 (SEO, 공통) |
| 이미지 과중(약 15MB) | ✅ 사실 (공통, 단 실사용자 속도는 통과) |
| 버튼 크기·간격 부족 + 버튼 이름 없음 | ✅ 사실 (모바일·데스크톱 공통) |
| **개인정보 동의 링크 깨짐** | ❌ **틀림 — 정상 작동** (PDF 정정 필요) |
| 대표 제목·메타 미정비 | ⚪ 존재는 함(누락 아님), 품질은 미검증 |
| 다국어 노출 / 의료진 홈 노출 | ⚪ 미검증 |

추가로 PSI가 잡은 것: 색상 대비 부족, viewport 확대 차단(user-scalable=no), 콘솔 JS 오류.

PSI 점수 — 모바일: 성능35 / 접근성71 / 권장92 / SEO85. 데스크톱: 성능56 / 접근성66 / 권장96 / SEO85. 실사용자(필드) 코어 웹 바이탈은 모바일·데스크톱 모두 '통과'.
