# 머리하는 깍새 — 쇼츠 배경 템플릿 (v2)

'흑백요리사' 셰프 관련 바이럴 쇼츠에서 검증된 **커뮤니티 인기 게시글** 스타일의
유튜브 쇼츠 배경입니다. (1080×1920)

실제 편집 영상('쓰리스타킬러' 쇼츠)의 컷 구성을 실측해 레이아웃을 맞췄습니다:
**콘텐츠(밈·실사) 정사각 컷 + 그 아래 자막** 포맷 기준.

| 파일 | 설명 |
|---|---|
| `template.html` | 배경 디자인 원본. 제목 등 텍스트를 여기서 수정 |
| `render.sh` | Chromium 헤드리스로 PNG 렌더링 |
| `output/background.png` | 최종 배경 (1080×1920) |
| `output/background@2x.png` | 고해상도 배경 (2160×3840) |
| `output/preview.png` | 콘텐츠·자막 위치 가이드가 표시된 미리보기 |
| `fonts/` | 지마켓 산스 Light/Medium/Bold (SIL OFL, 상업적 사용 가능) |

## 레이아웃 좌표 (1080×1920 기준)

| 구역 | 위치 | 비고 |
|---|---|---|
| 앱바(뒤로가기+채널 필) | y44–136 | 우상단 가짜 아이콘 제거 — 유튜브 실제 검색·카메라 아이콘과 중복 방지 |
| 인기 배지 | y172–232 | |
| 제목 (2줄) | y246–430 | 72px, 넘치면 JS가 54px까지 자동 축소 |
| 메타 (조회·추천·댓글) | y444–492 | |
| 가위 절취선 | y528 | |
| **콘텐츠 프레임** | **x100–980 / y566–1446 (880×880)** | 밈·실사 컷을 프레임 안에 꽉 채워 배치 |
| **자막 영역** | **y1486–1646 (좌우 90px 여백)** | 권장: 지마켓 산스 Bold 46px, 강조 단어 노란 하이라이트 |
| 하단 여백 | y1650–1920 | **비워 둘 것** — 유튜브 채널명·설명·음악바가 덮는 구역 |

유튜브 쇼츠 UI 세이프존도 반영되어 있습니다:
우측 버튼 열(x940~, y1020–1700)은 콘텐츠 프레임 테두리에만 살짝 걸치고,
제목·메타·자막은 모두 안전 영역 안에 있습니다.

## 영상마다 바꾸는 법

`template.html`에서 아래만 수정 후 `./render.sh` 실행:

1. **제목** — `<h1 class="title">` 내부. 2줄 권장, 강조 단어는 `<span class="hl">단어</span>`
2. **메타 숫자** — `.meta` 의 조회/추천/댓글 수

자막은 배경에 굽지 않고 편집기(프리미어·캡컷 등)에서 y1486–1646 영역에 얹습니다.
컷(밈 이미지·실사 클립)은 콘텐츠 프레임(880×880) 위에 얹으면 됩니다.

## 렌더링

```bash
cd shorts-bg
./render.sh   # Chromium 필요 (CHROME=경로 로 재지정 가능)
```
