# 머리하는 깍새 — 쇼츠 배경 템플릿

'흑백요리사' 셰프 관련 바이럴 쇼츠에서 검증된 **커뮤니티 인기 게시글** 스타일로 리디자인한
유튜브 쇼츠 배경입니다. (1080×1920)

| 파일 | 설명 |
|---|---|
| `template.html` | 배경 디자인 원본. 제목·댓글 등 텍스트를 여기서 수정 |
| `render.sh` | Chromium 헤드리스로 PNG 렌더링 |
| `output/background.png` | 최종 배경 (1080×1920) |
| `output/background@2x.png` | 고해상도 배경 (2160×3840) |
| `output/preview.png` | 영상이 들어갈 위치 가이드가 표시된 미리보기 |
| `fonts/` | 지마켓 산스 Light/Medium/Bold (SIL OFL 라이선스, 상업적 사용 가능) |

## 디자인 개요

- **컨셉**: 실시간 인기 게시글 UI — 상단 앱바(뒤로가기·검색·메뉴) + 채널 필 로고 +
  인기 배지 + 대형 제목(형광펜 하이라이트) + 조회수 메타 + 영상 프레임 + 추천/댓글 반응 바 + 베스트 댓글
- **브랜딩**: 채널 프로필(파랑새+가위)을 SVG로 재현해 앱바·아바타에 배치, 크림 배경색 통일,
  가위 절취선 디바이더로 이발 컨셉 강조
- **타이포**: 지마켓 산스 (제목 Bold 100px, 자간 -3px)
- **스타일**: 굵은 먹선 + 하드 오프셋 섀도(네오 브루탈) — 카툰풍 프로필과 톤 일치

## 영상마다 바꾸는 법

`template.html`에서 아래 세 곳만 수정 후 `./render.sh` 실행:

1. **제목** — `<h1 class="title">` 내부. 강조 단어는 `<span class="hl">단어</span>`
2. **조회수/시간** — `.meta` 의 `조회 24.8만`, `10분 전`
3. **베스트 댓글** — `.best` 의 닉네임·댓글·추천수 (영상 내용에 맞는 드립으로)

영상 클립은 `output/preview.png`에 표시된 흰색 프레임 영역(44,832 ~ 1036,1604) 위에 얹으면 됩니다.

## 렌더링

```bash
cd shorts-bg
./render.sh   # Chromium 필요 (CHROME=경로 로 재지정 가능)
```
