0 총평 — 한 장으로 보기

수정본은 ‘보여지는 경험’은 분명히 좋아졌습니다. 다만 환자를 ‘데려오고(발견)’ 전환을 ‘측정’하는 마케팅 엔진이 아직 비어 있어, 좋아진 콘텐츠가 성과로 연결되지 못할 위험이 있습니다.
좋아진 점이미지 18→92장, 유튜브 숏폼 노출 3배+, 시그니처 시술(안면윤곽·코·쌍꺼풀) 부각 → 신뢰·체류·브랜드 인상 개선
보완 필요전환 측정 0, CTA 정리·동의링크 수정, 의료진 신뢰정보 미노출, 검색·AI 발견 토대 미반영
후퇴분석도구(에이스카운터) 제거, 이미지 설명 태그 미흡

1 잘 반영되어 좋아진 점

환자가 ‘보는 화면’의 완성도와 진료 강점 전달력이 분명히 향상됐습니다. 실측 수치 기준입니다.

좋아진 항목이전 → 수정본마케팅 효과
비주얼 강화이미지 18장 → 92장첫인상·신뢰감 향상, 시술 결과의 시각적 전달력 강화
영상(유튜브 숏폼)노출 약 3배+ (관련 요소 25 → 85)체류시간 증가, 원장님·병원에 대한 친근감과 전문성 전달
시그니처 시술 부각안면윤곽 5→14, 코성형 21→33, ‘시그니처’ 섹션 신설병원의 진료 강점이 명확해져 타깃 환자 설득력 향상
섹션 구조화대표 소제목(H2) 0개 → 2개페이지가 ‘읽히는 구조’로 부분 개선(추가 정비 여지 있음)
상담 동선 유지전화 노출 4→6, 빠른상담·예약·카카오·후기·안전시스템 유지즉시 상담 진입점 확대, 기존 전환 동선은 보존

2 마케팅 관점 보완 필요 (핵심)

‘보여주기’는 좋아졌지만, 마케팅의 핵심인 ‘데려오기(발견)’와 ‘측정’은 비어 있습니다.

보완 항목현재 상태마케팅 영향
전환 측정 최우선구글·메타·카카오 측정 태그 0 (방문 카운터만)어떤 광고·콘텐츠가 상담으로 이어지는지 모름 → 광고비 깜깜이, 재방문 환자 리타게팅 불가
CTA 정리빠른상담·예약·온라인상담·카카오·전화가 동시에 경쟁, 기본 행동 불명확 + 개인정보 동의 링크 깨짐전환율 저하 + 개인정보 수집 관련 신뢰·법적 리스크
의료진 신뢰정보전문의·전담 마취과 전문의 등 강점이 홈에 드러나지 않음(서브페이지에만 있음)성형 의사결정의 핵심 신뢰 자산 미활용 → 전환 기회 손실
검색·AI 발견구조화 데이터·고유 페이지 설명·대표 제목 미정비신규 환자가 검색·AI로 병원을 ‘발견’하는 단계가 약함
다국어(해외환자)7개 언어가 검색에 사실상 미노출(구글 번역 위젯 방식)해외환자 유입 자산이 잠겨 있음
모바일 속도이미지 92장에 지연로딩(lazy) 미적용모바일 로딩 지연 → 첫 화면 이탈률 증가 우려
참고전환 측정, 어떻게 하나요?
무엇을 측정하나 빠른상담 제출·전화 탭·카카오 상담·예약 같은 환자 행동을 집계해, 어떤 유입 경로·광고가 실제 상담으로 이어졌는지 확인합니다. (현재는 방문 수만 카운트)
비용 — 도구는 무료 GA4·구글 태그매니저·메타/카카오 픽셀·서치콘솔은 모두 무료입니다. 비용은 ① 설치 대행 시 세팅 인건비, ② 광고 운영 시 광고비(측정과 별개)에만 발생 — ‘전환측정=유료’가 아닙니다.
설치 순서 ① 전환 정의② GA4 측정ID 발급 (무료)③ 사이트에 코드 삽입④ 버튼을 핵심 이벤트로 설정⑤ (광고 시) 픽셀 연동⑥ 개인정보 동의 링크 수정
※ ③ 코드 삽입은 소스·CMS 권한이 필요해 병원/개발사 작업으로 분리되며, ⑥ 동의 링크 수정은 상담정보 수집에 따른 법적 필수 항목입니다.

범위 : 홈페이지 직접 수정이 아닌, 점검 · 구조 설계 · 개선 파일 제작 · 개발사 전달 패키지 제공

총 기간1~2주차3~4주차분리 항목

2 주차별 일정

기간단계핵심 목표 프로젝트팀 수행병원/개발사 협조 필요주요 산출물
1주차0~1단계 초기 방향 확정 및 홈페이지 외부 점검 초기 미팅, 우선 시술·국내/해외 키워드 정리, 코성형-황숭오 원장 연결 방향 확인, robots.txt·sitemap·메타·스키마·내부링크·텍스트 구조 점검 원장님 진료 방향, 우선 시술, 강조 의료진, 사용 가능 표현 확인. 관리자/서버/소스 접근은 병원 또는 개발사 권한 필요 초기 미팅 정리본, 핵심 키워드 정리표, 홈페이지 AI 검색 대응 현황 점검표
2주차2단계 AI 검색 대응 구조 설계 병원 엔티티 구조 정리, 의료진-시술 연결 구조 설계, 국내/영문 키워드 매핑, 우선 반영 페이지 선정, 내부링크 방향 설계 병원 측 우선순위와 표현 방향 최종 확인 AI 검색 대응 구조 설계서, 엔티티 계층표, 키워드-페이지 매핑표
3주차3단계 개선 파일 및 코드 초안 작성 robots.txt 개선안, llms.txt, ai.txt, 커스텀 스키마 JSON-LD 초안, 주요 페이지 메타 개선안 작성 파일 업로드, 페이지 코드 삽입, CMS 수정은 개발사 수행 필요 robots.txt 개선안, llms.txt, ai.txt, 스키마 코드 초안, 메타 개선표
4주차4~5단계 개발사 전달 패키지 및 최종본 전달 파일 위치, 코드 삽입 위치, 반영 우선순위, 확인 방법 정리. 원장님/병원 피드백 반영 및 최종 파일 패키지 정리 개발사에서 실제 서버 업로드 및 페이지 반영 진행. 반영 완료 후 공개 URL 전달 개발사 전달 가이드, 반영 우선순위표, 반영 체크리스트, 최종 납품본, 반영 후 검수 체크리스트

3 수행 범위 구분

구분내용
프로젝트팀 수행 가능홈페이지 외부 점검, robots.txt 개선안 작성, llms.txt 작성, ai.txt 작성, 커스텀 스키마 코드 초안 작성, 메타 개선표 작성, 내부링크 구조 제안, 개발사 전달 가이드 작성

4 일정 기준

4주 일정은 점검·구조 설계·개선 파일·개발사 전달 가이드 납품 기준입니다. 실제 업로드, 소스 수정, CMS 반영, 계정 설치는 병원/개발사 권한 작업으로 분리합니다.
