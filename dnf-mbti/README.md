# 나와 닮은 아라드의 전직은? — 던파 성향 테스트

던전앤파이터 플레이 스타일 12문항으로 유저의 성향(MBTI 16유형)을 판정하고,
성향과 꼭 닮은 **眞 각성(진각성) 전직 캐릭터**를 추천하는 웹/모바일 테스트입니다.

- **단일 파일 앱**: `index.html` 하나로 동작 (외부 라이브러리·서버 불필요)
- **모바일 퍼스트**: 520px 중앙 카드 레이아웃, 터치 최적화, 다크 판타지 UI
- **공유 최적화**: 결과별 URL(`?r=ENTJ`), Web Share API + 클립보드 폴백

## 기획 의도

- 던파 유저가 매일 겪는 상황(숙제 리셋, 공대 대기방, 경매장 실수, 이벤트 벼락치기)을
  선택지로 사용해 **"내 얘기잖아"** 하는 공감 포인트로 이탈 없이 12문항을 완주시킵니다.
- 결과 캐릭터는 **바이럴 단위**입니다. 결과 카드에 파티 궁합(잘 맞는 캐릭터)과
  라이벌(투닥거리는 캐릭터)을 함께 노출해 "너도 해 봐" 공유 동기를 만듭니다.
- 신규/복귀 유저에게는 16종 도감 화면이 곧 **전직 소개 페이지** 역할을 합니다.

## 결과 캐릭터 16종 선정 기준

1. **성격 분석**: 각 전직의 **眞(진각성) 스토리**(DNF 유니버스 수록)를 기반으로
   캐릭터의 기질·가치관을 MBTI 16유형에 매핑했습니다.
2. **인기 반영**: 2025~2026 기준 유저 선호가 높은 전직을 우선 배치했습니다.
   - 버퍼 선호도 1위 뮤즈, 스테디셀러 세라핌/세인트, 인기 버퍼 헤카테·팔라딘(세이비어)
   - 1티어 평가 여넨마스터(염제), 여귀검 간판 검제, 남귀검(검신·인다라천·블러드 이블),
     남거너(레이븐·옵티머스) 등 인구 상위 직업군 중심
3. **직업군 분산**: 특정 직업군 쏠림을 피하고 11개 직업군을 커버합니다.

| MBTI | 캐릭터(통칭) | 진각성 | 직업군 · 전직 |
|------|-------------|--------|----------------|
| ISTJ | 검신 | 眞 웨펀마스터 | 귀검사(남) · 웨펀마스터 |
| ISFJ | 세인트 | 眞 크루세이더 | 프리스트(남) · 크루세이더 |
| INFJ | 인다라천 | 眞 아수라 | 귀검사(남) · 아수라 |
| INTJ | 옵티머스 | 眞 메카닉 | 거너(남) · 메카닉 |
| ISTP | 레이븐 | 眞 레인저 | 거너(남) · 레인저 |
| ISFP | 염제 | 眞 넨마스터 | 격투가(여) · 넨마스터 |
| INFP | 이시스 | 眞 소환사 | 마법사(여) · 소환사 |
| INTP | 이터널 | 眞 빙결사 | 마법사(남) · 빙결사 |
| ESTP | 블러드 이블 | 眞 버서커 | 귀검사(남) · 버서커 |
| ESFP | 뮤즈 | 眞 뮤즈 | 아처 · 뮤즈 |

궁합 시스템: 16유형을 8쌍의 상호 보완 쌍(예: 검신 ISTJ ↔ 시라누이 ENFP)으로 묶어
서로가 서로의 "환상의 궁합"으로 연결되고, 라이벌 역시 8쌍 대칭(예: 염제 ↔ 이터널,
세라핌 ↔ 헤카테 버퍼 라이벌)으로 구성해 어느 결과에서든 다른 결과로 회유됩니다.

## 테스트 시스템

- 12문항 = 4개 지표 × 3문항 (E/I, S/N, T/F, J/P). 지표당 홀수 문항이라 **동점 없음**
- 선택지의 지표 방향(A/B 위치)을 문항마다 섞어 위치 편향을 줄였습니다
- 판정 로직: 지표별 2표 이상 → 해당 성향 (`computeType()` 참고)
- 결과 화면: 유형 칭호 / 성격 해설 / 아라드 플레이 스타일 / 眞 스토리 한 줄 /
  유저 인기 메모 / 파티 궁합·라이벌 / 공유·다시하기·도감

## 진각성 일러스트 넣는 법

저작권 문제로 저장소에는 공식 일러스트를 포함하지 않았습니다.
서비스 채널(공식 이벤트 페이지 등)에서 사용 승인된 이미지를 확보한 뒤:

1. 각 전직의 **진각성 일러스트**를 준비합니다
   (던파 공식 캐릭터 소개: https://df.nexon.com/pg/characters )
2. `images/` 폴더에 **MBTI 소문자 파일명**으로 저장합니다
   - 예: `images/entj.png` (검제), `images/esfp.jpg` (뮤즈) — png 우선, jpg 폴백
   - 권장 비율 4:3.4 (세로가 살짝 긴 카드), 상단 중앙 크롭 기준
3. 이미지가 없으면 캐릭터별 상징 엠블럼(이모지+전용 그라데이션)이 자동 표시되므로
   일러스트 없이도 배포 가능한 상태입니다
4. 공유 썸네일은 `images/og.png` (1200×630 권장)

> ⚠️ 넥슨/네오플 IP 자산입니다. 대외 서비스 시 라이선스 협의 또는
> 공식 크리에이터 가이드라인 준수가 필요합니다.

## 실행 & 배포

```bash
# 로컬 실행: 파일을 브라우저로 열기만 하면 됩니다
open dnf-mbti/index.html

# 또는 간단한 로컬 서버 (공유 URL 테스트용)
cd dnf-mbti && python3 -m http.server 8000
```

정적 파일 하나이므로 GitHub Pages, Netlify, 사내 CDN 등 어디든 그대로 올리면 됩니다.

## 커스터마이징 포인트
