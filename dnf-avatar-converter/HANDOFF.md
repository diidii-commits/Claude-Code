# 던파 도트 캐릭터 변환기 — 인수인계 (핸드오프)

던전앤파이터(DNF) 도트 변환 프로젝트를 다른 세션(Opus 등)에서 이어가기 위한 요약.
이 파일 하나만 읽으면 전체 맥락을 파악하고 작업을 이어갈 수 있도록 작성됨.

## 프로젝트 목표

**사진을 넣으면 PC 던전앤파이터 게임의 아바타와 동일한 디자인의 도트 캐릭터로
자동 변환해주는 웹 시스템** 제작.

- 사용자가 제공한 참고 자료: 던파 전 캐릭터 "기본내의" 아바타 스프라이트 시트 2장
  (남캐 7종 + 여캐 9종, 흰/빨/검 3색 속옷 아바타 버전 포함, 회색 #808080 배경)
  - ⚠️ **이 참고 이미지들은 레포에 커밋되어 있지 않음** (채팅 첨부로만 존재).
    이어서 작업할 세션에서 필요하면 사용자에게 다시 첨부 요청할 것.
- 사용자가 제공한 베이스: "메이플스토리 풍으로 바꿔주는 프롬프트" 전문
  (픽셀 아트 디렉터 역할 정의 → 특징 분석 → FRAME SPEC → PIXEL RENDERING SPEC
  → 출력 조건 → 절대 금지 목록 구조). 이 구조를 유지하며 던파 스펙으로 재작성하는 것이 요구사항.

### index.html 구조 (단일 파일, 의존성 0)

- **업로드**: 드래그&드롭 + 클릭 업로드, 미리보기, base64 변환
- **API 2종 지원** (완전 클라이언트 사이드, 브라우저에서 직접 fetch):
  - Google Gemini: `POST https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash-image:generateContent?key=...`
    — parts에 `{text: 프롬프트}` + `{inline_data: {mime_type, data}}`, `generationConfig.responseModalities: ['IMAGE','TEXT']`,
    응답의 `candidates[0].content.parts[].inlineData`에서 이미지 추출 (camelCase/snake_case 둘 다 처리함)
  - OpenAI: `POST https://api.openai.com/v1/images/edits` — multipart form (`model=gpt-image-1`, `image`, `prompt`, `size=1024x1024`), 응답 `data[0].b64_json`
- **API 키**: localStorage(`dnf-converter-keys`)에 provider별 저장, 서버 전송 없음
- **프롬프트**: `DNF_PROMPT` 상수(스크립트 최상단)에 내장, `<details>` 안 textarea에서 수정 가능,
  [프롬프트 복사] 버튼으로 API 키 없이 ChatGPT/Gemini 웹에서 쓰는 우회 경로 제공
- **결과**: `image-rendering: pixelated`로 표시, PNG 다운로드, 다시 생성 버튼
- ⚠️ `PROMPT.md`와 `index.html`의 `DNF_PROMPT` 상수는 **수동 동기화** 관계.
  프롬프트를 수정하면 두 곳 모두 고칠 것 (index.html 쪽은 약간 압축된 버전).

## 핵심 설계 결정 (프롬프트)

메이플 프롬프트 구조를 유지하되 스펙을 던파 스프라이트 시트 분석 결과로 교체:

| 항목 | 메이플 (원본) | 던파 (재작성) |
|------|------------|--------------|
| 등신 | 2.0~2.3등신 치비 | **6.5~7.5등신 사실 비례**, 머리 13~15% / 몸통 35% / 다리 50% |
| 시점 | 45도 쿼터뷰 | 벨트스크롤 마을 대기 시점, 정면 10~20도, 눈높이 |
| 얼굴 | 큰 눈·홍조·코 금지 | 2~4픽셀 날카로운 눈, 코 1~2픽셀 음영, 입 생략 |
| 스프라이트 크기 | 32~64px 확대 | **120~160px 확대** |
| 음영 | 플랫 | 셀 셰이딩 덩어리, 좌상단 광원, 구릿빛 피부 셰이딩, 어두운 1px 외곽선 |
| 배경 | 흰색 | **회색 #808080** (던파 아바타 시트 배경색) |
| 장비 슬롯 | 메이플 8슬롯 | 던파 슬롯: 머리/모자/얼굴/상의/하의/신발/허리/피부/무기 |

**가장 중요한 인사이트**: 이미지 생성 AI는 "한국 게임 도트 캐릭터"를 그리라고 하면
메이플식 치비로 흘러가는 경향이 강함. 그래서 프롬프트 여러 위치(비율 섹션, 절대 금지
목록 최상단, 마지막 지시문)에 **"MapleStory Style / Chibi / 2등신 절대 금지"를 반복
명시**한 것이 핵심. 프롬프트를 개선할 때도 이 반복을 제거하지 말 것.

## 검증 상태 / 알려진 한계

- HTML/JS는 정적 검토만 완료. **실제 API 키로 엔드투엔드 생성 테스트는 아직 안 함**
  (원격 세션이라 사용자 API 키 없음). 이어받는 세션에서 최우선으로 확인할 것.
- OpenAI `gpt-image-1`은 조직 인증(verification) 필요 — README와 UI 힌트에 명시해둠.
- 브라우저 직접 호출 구조라 API 키가 클라이언트에 노출됨(본인 키를 본인 브라우저에서
  쓰는 개인 도구 전제). 배포용으로 만들려면 서버 프록시 필요 → TODO 참고.
- 생성형 특성상 결과 편차 있음. 사용자에게 2~3회 재생성 안내함.
