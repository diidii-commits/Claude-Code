ℹ️ 사용 방법

① 변환할 인물/캐릭터의 전신 사진을 업로드합니다. ② 사용할 이미지 생성 API의 키를 입력합니다 (Gemini 키는 Google AI Studio, OpenAI 키는 OpenAI Platform에서 무료/유료 발급). ③ [변환하기]를 누르면 던전앤파이터 아바타 스프라이트 화풍(6.5~7등신 사실 비례, 수작업 도트, 셀 셰이딩, 회색 배경)으로 재해석된 캐릭터가 생성됩니다.
API 키가 없다면 [프롬프트 복사] 버튼으로 프롬프트를 복사한 뒤, ChatGPT나 Gemini 웹사이트에 사진과 함께 붙여넣어도 동일한 결과를 얻을 수 있습니다. API 키는 서버로 전송되지 않고 사용자의 브라우저(localStorage)에만 저장됩니다.
