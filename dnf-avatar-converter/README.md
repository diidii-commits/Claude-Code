# 던전앤파이터(DNF) 도트 캐릭터 변환기

사진을 업로드하면 **PC 던전앤파이터의 플레이어 아바타 스프라이트 화풍**의 도트 캐릭터로
변환해주는 웹 시스템입니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 변환기 웹페이지 (단일 파일, 서버 불필요) |
| `PROMPT.md` | 던파 화풍 변환 프롬프트 원문 (ChatGPT/Gemini 등에 직접 사용 가능) |

## 사용 방법

### 방법 1 — 웹페이지 사용 (자동 변환)

1. `index.html`을 브라우저로 엽니다. (더블클릭으로 바로 실행 가능, 별도 서버 불필요)
2. 변환할 인물/캐릭터의 **전신 사진**을 업로드합니다.
3. 이미지 생성 API 키를 입력합니다.
   - **Google Gemini (추천)**: [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 발급 → `gemini-2.5-flash-image` 모델 사용
   - **OpenAI**: [OpenAI Platform](https://platform.openai.com/api-keys)에서 발급 → `gpt-image-1` 모델 사용 (조직 인증 필요)
4. **[던파 도트로 변환하기]** 버튼을 누르면 결과가 표시되고 PNG로 저장할 수 있습니다.

> API 키는 서버로 전송되지 않으며 사용자 브라우저의 localStorage에만 저장됩니다.
> 브라우저에서 각 API를 직접 호출하는 완전한 클라이언트 사이드 구조입니다.

### 방법 2 — 프롬프트만 사용 (API 키 없이)

`PROMPT.md`의 프롬프트(또는 웹페이지의 [프롬프트 복사] 버튼)를 복사한 뒤,
ChatGPT · Gemini · Midjourney 등의 이미지 생성 AI에 **사진과 함께** 붙여넣으면
동일한 던파 화풍 결과를 얻을 수 있습니다.

## 던파 화풍 프롬프트의 핵심 설계

메이플스토리 변환 프롬프트를 기반으로 하되, 두 게임의 도트 스타일 차이를 반영해
스펙을 전면 재작성했습니다.

| 항목 | 메이플스토리 | 던전앤파이터 (본 프롬프트) |
|------|------------|--------------------------|
| 등신 비율 | 2.0~2.3등신 (치비/SD) | **6.5~7.5등신 사실 비례** |
| 머리 비중 | 전체의 60~65% | 전체의 13~15% |
| 시점 | 35~45도 쿼터뷰 | 벨트스크롤 마을 대기 시점 (정면 10~20도) |
| 얼굴 | 큰 눈 + 하이라이트, 홍조 | 2~4픽셀의 작고 날카로운 눈, 최소 표현 |
| 신체 | 원통형 짧은 팔다리 | 근육/체형 실루엣이 살아있는 긴 팔다리 |
| 음영 | 플랫 셰이딩 | 셀 셰이딩 덩어리 + 강한 명암 (네오플 수작업 도트) |
| 스프라이트 크기 | 32~64px 확대 느낌 | **120~160px 확대 느낌** |
| 배경 | 흰색 (#FFFFFF) | **회색 (#808080)** — 던파 아바타 시트 배경색 |
| 절대 금지 | 타 게임 스타일 | + **MapleStory/치비 비율 금지** (최다 실패 원인) |

특히 이미지 생성 AI가 "한국 게임 도트 캐릭터"를 그리면 메이플식 치비로 흘러가는 경향이
강하기 때문에, 프롬프트 곳곳에 치비/SD 비율 금지를 반복적으로 명시한 것이 핵심입니다.

## 결과 품질 팁

- **전신 사진**을 넣을수록 의상·체형 재현율이 올라갑니다.
- 원하는 결과가 아니면 [다시 생성]을 2~3회 시도해보세요 (생성형 특성상 편차가 있음).
- 프롬프트는 웹페이지의 "변환 프롬프트 보기/수정"에서 자유롭게 수정할 수 있습니다.
  예: 특정 직업(귀검사, 격투가 등) 체형을 강제하고 싶으면 `[DNF PLAYER FRAME SPEC]`의
  체형 항목에 추가하면 됩니다.
